# Как прекрасна жизнь — Лягушка-трейдер

**Живой торговый мир с JARVIS-наставником и душой Лягушки.**

Это Telegram Mini App, где торговый терминал не заменяет мир, а живёт внутри него.

## Концепция

- 🌊 **Долина Рек** — главный экран и первая точка пути.
- 🐸 **Лягушка ИИ** — спокойный наставник: факты → сценарии → риск → решение пользователя.
- ✨ **Светлячки ИИ** — слой наблюдения и сигналов.
- 🎣 **Рыбы** — игровые награды за наблюдение и дисциплину.
- 🗺️ **Карта пути** — Долина Рек → Лес Дисциплины → Река Терпения → Гора Риска → Вершина Свободы.
- 📖 **Дневник** — память о решениях и наблюдениях.
- 🎒 **Рюкзак** — накопленные игровые ресурсы.
- 🏪 **Лавка** — будущие улучшения лагеря.
- ⚡ **Сделка** — торговый терминал поверх живого мира.
- 📊 **Аналитика** — калькулятор позиции и торговые данные.

## Визуальный принцип

Главный экран — это не dashboard из карточек. Это живой лагерь: фон, река, маршрут, атмосферные эффекты, дневной/ночной режим и Лягушка рядом с трейдером.

## Стек

React + TypeScript + Vite + Tailwind CSS + Framer Motion + Telegram Mini Apps SDK.

## Backend

Python/FastAPI отвечает за AI-анализ скриншотов, MOEX-данные и Smart Exit. Для frontend используется переменная:

`VITE_API_BASE_URL=https://your-api.example.com`

Если переменная не задана, приложение обращается к текущему origin.

## Vercel

Репозиторий подключается к Vercel через GitHub. После push в production-ветку Vercel может автоматически создать новый production deployment; актуальную схему Git Integration следует проверять в настройках проекта.
